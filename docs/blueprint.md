# **App Name**: NutriNexus

## Core Features:

- Firebase Identity Access: Simple email and password authentication allowing users to securely manage their personal profiles and health records across devices.
- Vital Profile & Goal Logic: Calculates daily caloric and macronutrient needs based on height, weight, age, and activity level using industry-standard nutritional formulas.
- Live Progress Dashboards: A dynamic interface showcasing daily targets for calories, proteins, carbohydrates, and fats through responsive, easy-to-read progress bars.
- NutriScan AI Vision Tool: Utilizes the device camera and Gemini AI as a tool to reason through food images and estimate nutritional macro counts automatically.
- Monetized Scanning Experience: Integrates Google AdMob to display interstitial ads before activating the AI food scanning sequence, ensuring sustainable free app usage.
- Daily Nutritional Chronology: A chronological feed powered by Cloud Firestore that lets users view and review every food item logged during the day.
- Tri-Lingual System Toggle: Supports a native user interface available in English, Estonian, and Russian, instantly switchable via settings.

## Style Guidelines:

- Primary Color: Deep Royal Indigo (#56479F), conveying precision and a modern health-tech feel.
- Background Color: Pale Quartz (#F5F4F8), providing a crisp, high-contrast workspace for nutrition data.
- Accent Color: Azure Energy (#557EEB), used for CTA buttons and highlighted progress indicators, offering 30-degree analogous separation from the primary.
- Headline Font: 'Poppins' for a geometric, modern tech appearance; Body Font: 'Inter' for high readability in dense data logs.
- Linear and minimalist outline icons that align with Android's Material Design system for a familiar mobile user experience.
- Mobile-first card-based architecture optimized for high-density nutritional information, featuring large touch targets for handheld efficiency.
- Smooth micro-interactions for the daily macro bars that tween upward based on current log totals to provide visual satisfaction.
